# Preferências de trabalho

- Usar os plugins e skills instalados em todas as etapas do projeto:
  - `headroom` para arquivos grandes (relatórios HTML do PJe-Calc, logs do Tomcat): outline primeiro, ler só o necessário.
  - Memória estruturada (`claude-memory`) para registrar decisões que precisam valer entre sessões.
  - `task-observer` para registrar correções e preferências duradouras neste arquivo.
  - `claude-code-setup` para recomendar automações (hooks, skills, subagentes) quando o fluxo mudar.
  - Antes de cada commit de código: `code-review`, `simplify` e `security-review`.
